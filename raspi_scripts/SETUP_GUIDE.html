1   System Overview

Road Sentinel uses two Raspberry Pis and one LED matrix panel positioned at a blind curve. Both cameras feed into the AI detection pipeline. The Pi 5 drives the LED matrix, which warns drivers approaching the curve.

┌─────────────────┐ ┌──────────────────────┐ │ Raspberry Pi 4 │ │ Raspberry Pi 5 │ │ (Camera A) │ │ (Camera B + LED) │ │ │ │ │ │ cam_sender.py │ │ cam_sender.py │ │ pi_agent.py │ │ display_manager.py │ └────────┬────────┘ │ pi_agent.py │ │ detections └──────┬───────────────┘ │ incidents │ detections + polls ▼ ▼ ┌────────────────────────────────────────────────────┐ │ Node API :3001 + AI Service :8000 │ │ (runs on your server / laptop) │ └────────────────────────────────────────────────────┘ │ polls every 2s ▼ ┌──────────────────┐ │ HUB75 LED Panel │ │ 128 × 32 pixels │ │ (on Pi 5) │ └──────────────────┘

Detection → Display Flow

  1. Camera A (Pi 4) or Camera B (Pi 5) captures a frame and sends it to the AI service.
  2. AI detects vehicles or incidents → result is forwarded to the Node API.
  3. display_manager.py on Pi 5 polls /api/detections every 2 seconds.
  4. If a detection is less than 8 seconds old → LED shows VEHICLE INCOMING.
  5. If an incident is confirmed → LED shows INCIDENT AHEAD.
  6. When the road has been clear for 15+ seconds → LED shows VACANT ROAD.

3   Prerequisites — Both Pis

3.1   Flash Raspberry Pi OS

Do this for each Pi before doing anything else.

1 Download Raspberry Pi Imager

Download from raspberrypi.com/software and install on your laptop.

2 Flash the SD card

Open Imager → Choose OS → Raspberry Pi OS Lite (64-bit) → Choose Storage → your SD card.

Before clicking Write, click the gear icon ⚙ and configure:

SettingPi 4 valuePi 5 value
Hostnamepi4-sentinelpi5-sentinel
Usernamepipi
Passwordyour choiceyour choice
Wi-Fi SSIDyour network name
Wi-Fi Passwordyour network password
Enable SSH✓ Yes — Use password authentication
Locale / TimezoneAsia/Manila
3 Boot and find the IP

Insert the SD card, connect power, wait 60 seconds for first boot. Find the Pi's IP address in your router admin page (usually 192.168.8.x or 192.168.1.x).

3.2   First SSH Login

From your laptop terminal (or PowerShell on Windows):

# Pi 4
ssh pi@<pi4-ip-address>

# Pi 5
ssh pi@<pi5-ip-address>

After setup completes you will never need the IP again — use the hostname instead:

ssh pi@pi4-sentinel.local
ssh pi@pi5-sentinel.local
ℹ Note — Windows SSH If ssh is not found in PowerShell, open Settings → Apps → Optional Features → Add: OpenSSH Client.

4   Raspberry Pi 4 Setup (Camera A only)

ℹ Pi 4 has NO LED matrix. Pi 4 runs Camera A only. Its detections are forwarded to the Node API, which Pi 5 polls to update the LED display in real time.

4.1   Run the Setup Script

SSH into Pi 4, then run:

# Download and run the setup script in one command.
# Replace the three values below with your actual addresses.

bash <(curl -fsSL https://raw.githubusercontent.com/Shaloh69/Road_Sentinel/main/raspi_scripts/setup_pi4.sh) \
  http://<SERVER_IP>:3001 \
  "rtsp://<CAM_A_IP>:554/cam/realmonitor?channel=1&subtype=1" \
  http://<SERVER_IP>:8000
PlaceholderReplace withExample
<SERVER_IP>IP of the laptop/PC running the server192.168.8.50
<CAM_A_IP>IP of the RTSP camera near Pi 4192.168.8.104

The script will automatically:

  • Set the hostname to pi4-sentinel
  • Install system packages (Python, OpenCV, ffmpeg, git)
  • Clone the Road Sentinel GitHub repository
  • Create a Python virtual environment with all dependencies
  • Install roadsentinel-camera and roadsentinel-agent systemd services
  • Create start.sh, stop.sh, status.sh, update.sh helper scripts
  • Start both services immediately

4.2   Reboot and Verify

sudo reboot

After reboot, SSH back in and check:

~/roadsentinel/status.sh

Expected output — both services should show active (running):

=== Camera Sender ===
● roadsentinel-camera.service — Road Sentinel Camera A Sender
   Active: active (running)

=== Pi Agent (Admin Terminal) ===
● roadsentinel-agent.service — Road Sentinel Pi Agent
   Active: active (running)
✓ Pi 4 setup complete. Camera A is now streaming to the AI service and forwarding detections to the Node API. Pi 5's LED will react to these detections within 2 seconds.

The script installs:

  • System packages + Python venv + OpenCV + dependencies
  • hzeller rpi-rgb-led-matrix library (cloned, compiled)
  • led-image-viewer binary (used by the LED display backend)
  • Three systemd services: camera, display, agent
  • Helper scripts in ~/roadsentinel/

5.2   Build led-image-viewer (critical for LED)

🔴 Do not skip this step. The setup script clones the hzeller library, but you must build led-image-viewer manually. Without it the display service fails silently. 
# Build led-image-viewer for the Pi 5 display backend
cd ~/rpi-rgb-led-matrix
make -C utils led-image-viewer -j2

# Confirm the binary exists
ls -lh utils/led-image-viewer

Expected output: a binary file around 200–500 KB.

-rwxr-xr-x 1 pi pi 312K  led-image-viewer
⚠ Do NOT use --led-rp1-rio=1 This flag enables an experimental GPIO mode that causes rapid display corruption on Pi 5. It is disabled in all scripts. Never add it manually.

5.4   Test the LED Display

Stop the display service first (it holds the GPIO), then run the test script:

# Stop running display service and kill any lingering viewer process
sudo systemctl stop roadsentinel-display
sudo pkill -f led-image-viewer; sleep 1

# Run the auto-cycle test (SLOW DOWN → VEHICLE INCOMING → VACANT ROAD)
sudo python3 ~/roadsentinel-repo/raspi_scripts/test_display.py

The panel will cycle through the three screens every 5 seconds. The display blinks briefly every 1.4 seconds — this is normal and intentional (it resets the RP1 PWM timing to prevent display corruption).

Press Ctrl+C to stop. Then restart the display service:

sudo systemctl start roadsentinel-display

6   Display States & Behavior

The LED matrix on Pi 5 shows one of four screens at any time. Priority runs top to bottom:

#ScreenColorTriggerDuration
1 INCIDENT AHEAD Magenta Incident confirmed by either camera (crash, speeding, wrong-way, etc.) 12 s hold after last incident
2 VEHICLE INCOMING Orange Vehicle detected by Camera A or Camera B within the last 8 s 8 s hold after last detection
3 SLOW DOWN Red System running but road not yet confirmed clear (startup / camera offline) Until road confirmed vacant
4 VACANT ROAD Green Camera is live, no vehicle detected for 15+ seconds Until next detection

Blink Behavior

The display blinks (briefly goes black) every 1.4 seconds. This is by design — it resets the Raspberry Pi 5's RP1 co-processor PWM timing before drift causes display corruption. The content re-appears immediately after each blink. Any content change (e.g. VACANT ROAD → VEHICLE INCOMING) takes effect on the next blink, not mid-display.

Detection Source

Both cameras contribute to the LED display. display_manager.py polls GET /api/detections every 2 seconds. If the most recent detection from either camera is less than 8 seconds old, VEHICLE INCOMING is shown.

8   Updating Code on the Pi

Option A — From the Pi terminal

~/roadsentinel/update.sh

This pulls the latest code from GitHub, copies new scripts to ~/roadsentinel/, and restarts all services.

Option B — From the Web Dashboard (Admin Terminal)

  1. Open the Road Sentinel web dashboard in your browser.
  2. Go to Admin Terminal.
  3. Select Pi 4 or Pi 5 from the dropdown.
  4. Run: ~/roadsentinel/update.sh
ℹ Admin Terminal requires the agent service roadsentinel-agent must be running on the Pi and the Pi must be able to reach the Node API URL for the Admin Terminal to work.

Typical deploy workflow

# On your dev machine (Windows)
git push

# On each Pi (or via Admin Terminal)
~/roadsentinel/update.sh

10   Troubleshooting

ProblemCauseFix
LED shows random colors / garbage immediately RIO mode enabled or two led-image-viewer processes running sudo pkill -f led-image-viewer; sleep 1 then restart display service. Never add --led-rp1-rio=1.
LED text corrupts after a few seconds RP1 PWM timing drift Normal behavior — display blinks every 1.4 s to reset it. If still corrupting, check that --led-pwm-bits=3 and --led-slowdown-gpio=4 are in the flags.
Display service fails to start led-image-viewer binary not built Run: cd ~/rpi-rgb-led-matrix && make -C utils led-image-viewer -j2
Camera service not detecting vehicles RTSP URL wrong or camera offline Check camera.log. The script auto-discovers the new camera IP after 3 failures via ONVIF.
LED stuck on SLOW DOWN, never shows VACANT ROAD API not reachable or first 15 s not elapsed yet Wait 15 s after startup. Check display.log for API errors. Verify --api URL is correct.
Admin Terminal not working roadsentinel-agent not running or can't reach Node API Check agent.log. Run ~/roadsentinel/status.sh. Verify the Pi can reach the Node URL.
SSH connection refused after reboot Pi still booting (takes ~30 s) Wait 30–60 seconds and retry.
ssh pi@pi5-sentinel.local not working mDNS not available on your laptop Use the IP address instead. On Windows, install Bonjour or use ping pi5-sentinel.local to find the IP first.
make build error for hzeller library Missing build tools sudo apt install -y build-essential git then retry.
